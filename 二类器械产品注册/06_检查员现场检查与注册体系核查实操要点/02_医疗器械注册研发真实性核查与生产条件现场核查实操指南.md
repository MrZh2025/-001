# 医疗器械注册研发真实性核查与生产条件现场核查实操指南

> **适用场景**：境内第二类医疗器械注册现场核查、飞检、体系预审计与迎检准备  
> **核心导向**：落实《医疗器械监督管理条例》（国务院令第739号）关于“全过程信息真实、准确、完整和可追溯”的法定要求，指导检查员核查与企业迎检自查。

---

## 一、 研发真实性核查（R&D 穿行测试核查方法）

在注册体系核查中，**研发真实性**是检查员重点关注的审查领域。检查员通常采用**“从申报资料到原始记录、从样品批号到物料源头”**的反向追溯法进行穿行测试：

```
研发真实性核查反向追溯链条
【申报资料（PTR / 检验报告 / 综述资料）】
    ↓
【样品试制批记录】（投料量、生产日期、操作人员、设备运行日志）
    ↓
【原材料采购与质检追溯】（采购合同、发票、送货单、入库台账、检验原始记录、留样）
    ↓
【设计开发历史文档（DHF）】（立项报告、设计输入、评审纪要、验证确认原始报告、设计更改单）
    ↓
【仪器设备使用日志与原始数据】（仪器开机记录、天平称量记录、色谱仪电子数据与审计追踪 Audit Trail）
```

---

## 二、 核心核查模块与检查员核查技巧

### 1. 注册检验用样品试制真实性核查
- **核查物料消耗平衡**：
  - 检查员会核算试制样品批次的理论物料消耗量与实际领料量、库存剩余量是否吻合；
  - 核查物料进货批号是否在试制日期之前完成检验入库。
- **核查设备与环境运行日志**：
  - 调取试制样品生产当天的洁净车间温湿度/压差记录、空调净化系统（HVAC）运行记录；
  - 调取关键生产设备（如注塑机、封口机、贴片机）的开机运行记录及工艺参数设置。

### 2. 检验数据与自检真实性核查（ALCOA+ 原则）
- **数据完整性（ALCOA+）排查**：
  - **可归属性（Attributable）**：检验记录上的签名是否为操作者本人，有无代签；
  - **清晰性（Legible）**：记录是否字迹清晰，修改是否采用规范划改并签名注明日期；
  - **同时性（Contemporaneous）**：记录是否在试验发生时实时记录，严禁事后回忆补记；
  - **原始性（Original）**：提交的图谱是否为原始打印件或原始电子文件；
  - **准确性（Accurate）**：计算过程是否准确无误，有无随意舍弃异常数据。
- **电子仪器审计追踪（Audit Trail）核查**：
  - 检查员会对色谱仪、分光光度计等带计算机系统的检验仪器进行后台审计追踪日志查看，核查是否存在“反复进样筛选最好结果、删除未达标测试图谱、修改系统时间”等恶性作弊行为。

### 3. 灭菌确认与包装有效期研究真实性
- **灭菌记录核查**：
  - 委托灭菌的，核查灭菌合同、灭菌协议、每批灭菌交接单、灭菌过程参数曲线图（温度、湿度、压力、EO浓度、维持时间）及生物指示剂（BI）培养阴性报告；
  - 自建灭菌柜的，核查灭菌柜年度再确认报告及灭菌批记录。
- **老化试验箱记录核查**：
  - 核查加速老化试验箱/恒温恒湿箱的长期运行温度、湿度连续监控曲线；
  - 核查不同时间节点（如 0 月、3 月、6 月、12 月）取样出库检验的原始试验记录。

## 三、 生产条件现场核查实操要点

| 核查区域 | 检查要点 | 典型缺陷表现 |
| :--- | :--- | :--- |
| **洁净车间** | 压差梯度（洁净区对非洁净区 $\ge 10\text{Pa}$，相邻不同级别 $\ge 5\text{Pa}$）；人流更衣通道布局；物料传递窗（紫外/自净联动） | 压差计失灵或显示为 0；更衣室未设置压差梯度；高效送风口长期未检漏 |
| **公用工程** | 纯化水系统管路材质（316L/卫生级管路、无死角设计、循环回路）；储罐呼吸器完整性；定期消毒记录与水质全项检验报告 | 纯化水储罐呼吸器无更换记录；出水点水质微生物或电导率监测不及时 |
| **仓储与物料** | 原料、包材、中间品、成品分区明确；温湿度受控；不合格品专区加锁；物料状态标识清晰 | 原材料未贴状态标识（待验/合格/不合格混放）；退料、报废品随意丢弃无台账 |
| **工艺装备** | 生产模具、工装夹具专人管理与编号；设备日常点检记录；易损件更换记录 | 模具无编号，无法确认试制样品使用的是哪套模具；封口机温度未定期校准 |

## 四、 企业迎检准备（Checklist 自查清单）

在迎接省药监局注册质量管理体系现场核查前，企业应当提前 1~2 周完成以下自查闭环：

- [ ] **人员就位**：企业负责人、管理者代表、研发主管、生产主管、质量主管、核心检验员必须在场，熟悉申报产品技术细节；
- [ ] **资料归档（DHF）**：整理成册从立项、设计输入、输出、验证确认到试制批记录的全部纸质与电子档案，随调随取；
- [ ] **生产线动态演示准备**：生产车间清洁消毒完毕，准备好模拟物料，确保关键工序能够现场演示规范操作；
- [ ] **自检实验室现场考核准备**：检验仪器完成校准贴标，试剂在有效期内，检验员随时准备按 PTR 现场演示核心指标检验操作；
- [ ] **真实性承诺与自查报告**：签署企业质量安全与真实性承诺书，完成迎检汇报 PPT 编制。
