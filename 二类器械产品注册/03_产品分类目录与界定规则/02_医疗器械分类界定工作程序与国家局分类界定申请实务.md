# 医疗器械分类界定工作程序与国家局分类界定申请实务

> **法规依据**：《医疗器械监督管理条例》（国务院令第739号）第二十三条、《医疗器械分类界定工作程序》、《医疗器械分类规则》（总局令第15号）  
> **受理机构**：中国食品药品检定研究院（国家药品监督管理局医疗器械标准管理中心）  
> **适用情形**：新研制产品、未列入现有《医疗器械分类目录》的产品、或存在一类/二类/三类管理类别争议的产品。

---

## 一、 医疗器械分类判定的 4 大核心维度

根据《医疗器械分类规则》（总局令第15号），判定产品类别的核心要素：

1. **结构特征**：
   - 有源医疗器械（依靠电能或其他能源驱动）；
   - 无源医疗器械（不依赖能源，依靠机械力/物理作用）。
2. **使用形式与接触性质**：
   - 表面接触（皮肤、黏膜、损伤表面）；
   - 侵入器具（通过人体自然孔道侵入）；
   - 植入器具（部分/全部植入人体内部或替代生理组织）。
3. **接触时间**：
   - 暂时使用（$< 24$ 小时）；
   - 短期使用（$24$ 小时 $\sim 30$ 日）；
   - 长期使用（$> 30$ 日）。
4. **预期目的与风险程度**：
   - 是否维持/支持生命、是否对中枢神经/心血管系统产生影响、是否具有潜在不可逆损伤风险。

## 二、 国家局“医疗器械分类界定信息系统”在线申请 4 步法

```
分类界定官方申请全流程
【第 1 步】登录系统与账号注册
    └── 访问“国家药品监督管理局网上政务大厅 - 医疗器械分类界定信息系统”完成企业实名认证
        ↓
【第 2 步】在线填报《医疗器械分类界定申请表》
    ├── 拟定产品通用名称、结构组成、作用机理
    ├── 详述产品预期用途、适用范围、工作原理
    └── 提出申请人拟申请的管理类别（如：拟按第二类管理）及事实理由依据
        ↓
【第 3 步】上传 5 大核心证明附件（PDF盖章件）
    ├── 1. 产品技术报告（含主要技术指标、性能参数、结构外观图）
    ├── 2. 作用机理与临床使用说明（详述物理/机械作用过程，证明无药理作用）
    ├── 3. 关键原材料及与人体接触部件说明
    ├── 4. 境内外同类产品上市情况检索报告（若有）
    └── 5. 申请人营业执照与真实性承诺书
        ↓
【第 4 步】省局初审与国家标管中心专家评审
    ├── 申请人所在地省药监局（四川省药监局）在 5 个工作日内完成资料初审并转交国家局；
    └── 国家标管中心在 20 个工作日内出具《医疗器械分类界定结果告知书》并向社会公开。
```

## 三、 分类界定结果的三种法定结论

| 界定结论 | 法律效力与应对路径 |
| :--- | :--- |
| **① 属于第二类医疗器械** | 凭《分类界定告知书》，正式在**四川省药品监督管理局**启动第二类医疗器械产品注册申报 |
| **② 属于第一类医疗器械** | 凭《分类界定告知书》，前往所在地设区的**市级市场监督管理局/药监局**办理产品备案凭证 |
| **③ 属于第三类医疗器械** | 属于较高风险或高技术产品，需向**国家药品监督管理局（北京）**提交三类注册申请 |
| **④ 不作为医疗器械管理** | 属于普通电子产品、日用品、化妆品或消毒产品，**不得按照医疗器械申请注册或宣传疗效** |
