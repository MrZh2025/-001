# 境内第二类医疗器械注册质量管理体系现场核查工作程序与检查要点

> **依据规章**：《医疗器械注册与备案管理办法》（总局令第47号）  
> **核查规范**：《医疗器械生产质量管理规范》（GMP）及其附录、《境内医疗器械注册质量管理体系核查工作程序》  
> **核查主体**：四川省药品监督管理局指定的医疗器械核查机构 / 省级药品检查员专家组  
> **核心任务**：全面评估申请人是否建立与所申报产品相适应的质量管理体系，核实**研发过程真实性、注册检验批样品生产过程真实性以及是否具备该产品的实际生产和质量控制能力**。

---

## 一、 注册现场核查标准程序（现场 2~3 天实操流程）

```
检查员现场核查 5 步曲
【1. 首次会议】
    ├── 介绍检查组成员、宣读检查纪律及保密承诺
    ├── 确认检查目的、范围、日程安排
    └── 听取企业负责人对企业基本情况及申报产品研发/试制情况汇报
        ↓
【2. 现场动态与静态巡视】
    ├── 仓储区（原料库、包材库、中间品库、成品库、不合格品区、留样室）
    ├── 生产车间（洁净车间级别、人流物流通道、压差梯次、关键工艺工位）
    ├── 公用工程区（纯化水制备系统、注射用水系统、空调净化机组 HVAC、压缩空气系统）
    └── 质量控制实验室（理化室、仪器室、微生物限度室、阳性对照室、无菌检测室、自检实验室）
        ↓
【3. 分组核查与软硬件穿行测试】
    ├── 第一组（研发与注册）：核查设计开发输入输出、验证确认报告、风险管理、PTR对比、样品试制批记录
    └── 第二组（生产与质控）：核查工艺规程、设备验证、公用工程监测、自检原始图谱、物料追溯
        ↓
【4. 检查组内部评议与缺陷项沟通】
    ├── 检查组闭门汇总缺陷，对照 GMP 条款定性（严重缺陷 / 主要缺陷 / 一般缺陷）
    └── 与企业管理层沟通事实细节，确认事实客观性
        ↓
【5. 末次会议】
    ├── 检查组宣读《现场核查缺陷表》及综合现场核查初步结论
    └── 企业负责人签字确认（如对个别缺陷存有异议，可书面陈述申辩）
```

## 二、 GMP 现场核查核心章节与检查要点速查

### 1. 机构与人员
- **企业负责人**：是否熟悉医疗器械法律法规；是否提供充分资源；
- **管理者代表 / 质量负责人**：是否具备医学、药学、生物学、机械、电子等相关专业大专以上学历或中级以上技术职称，并具有 3 年以上医疗器械生产/质管实践经验；
- **自检人员 / 检验员**：是否具备独立完成产品技术要求（PTR）中各项指标检验的实际操作能力。

### 2. 厂房与设施
- 厂房选址与布局是否合理，人流、物流是否有效分开；
- 洁净室（区）温湿度、压差、送排风、沉降菌/浮游菌/尘埃粒子日常监测记录是否完整有效；
- 仓储区温湿度监控记录、物料分区标识（待验、合格、不合格）是否规范。

### 3. 设备与公用工程
- 纯化水系统、空调净化系统是否有完整的设计确认（DQ）、安装确认（IQ）、运行确认（OQ）、性能确认（PQ）验证报告；
- 关键生产设备（如注塑机、焊接机、贴片机、封口机）与检验仪器（拉力机、气相/液相色谱、耐压测试仪、示波器等）的运行记录及校准证书是否在有效期内。

> [!IMPORTANT]
> **【检查员必查：设计开发与研发真实性（一票否决重点）】**：

### 4. 设计开发（研发真实性核心核查区！）
- **立项与策划**：是否有《设计开发计划书》，职责划分清晰；
- **设计输入**：是否将法规强制性标准（GB/YY）、用户需求转化为技术指标输入；
- **设计输出**：是否有产品图纸、物料清单（BOM）、工艺规程、检验规程、说明书标签及《产品技术要求（PTR）》；
- **设计验证与确认**：
  - 各项性能测试报告、电气安全报告、生物相容性报告是否与设计输入指标闭环对应；
  - 注册检验样品的试制批记录（投料、称量、关键工序操作、巡检、中间品检验、成品放行）是否真实、完整、可追溯；
  - 试制样品所消耗的关键原材料采购凭证、入库检验报告是否真实对应。

### 5. 采购与物料管理
- 关键原材料供应商是否列入《合格供方名录》并经过严格评价与审计；
- 原材料采购技术标准与入库全检/抽检记录是否符合要求。

### 6. 生产管理与质量控制
- 关键工序与特殊过程（如注塑成型、超声焊接、涂层固化、无菌封口、EO灭菌等）是否完成参数工艺验证；
- 批号管理制度是否能实现从“原材料批号 -> 过程批号 -> 成品批号”的全链条双向正反向追溯；
- 检验原始记录与图谱（色谱图、试验曲线）是否具有时间戳和完整的数据完整性（ALCOA 原则）。

## 三、 现场核查结论判定标准

根据缺陷性质和数量，核查结论分为三种：

| 核查结论 | 判定标准 | 后续处理程序 |
| :--- | :--- | :--- |
| **① 通过检查** | 现场未发现主要缺陷，仅存在少量一般缺陷（通常 $\le 5$ 项一般缺陷且企业承诺整改） | 检查组出具建议通过意见，企业于规定期限内提交整改报告归档，直接进入行政审批 |
| **② 整改后复查** | 存在主要缺陷，或一般缺陷数量较多，但未构成严重系统性失控 | 企业在规定期限内（通常 30 个工作日内）完成整改并提交《整改报告》，检查机构视情况组织**现场复查或资料复查**，复查合格后通过 |
| **③ 未通过检查** | 存在**严重缺陷**（如研发数据造假、关键生产条件严重不符、无法溯源），或整改后复查仍不合格 | 检查机构出具“不通过”结论，省药监局依法作出**不予许可（不予注册）**决定 |

## 四、 检查员现场判定“一票否决”与常见红线问题

> [!CAUTION]
> **注册体系核查红线（一票否决情形）**：
> 1. **研发与样品试制数据造假**：样品试制批记录无真实生产迹象、物料台账与仓库出入库数据对不上、伪造检验原始记录与色谱图谱；
> 2. **生产场地与申报资料严重不符**：注册申报地址为空壳场地、关键生产或检验设备根本不存在；
> 3. **自检能力造假**：申报提交了自检报告，但现场抽查发现企业无相应检测设备或检验员完全不会操作；
> 4. **关键原材料擅自更改**：实际生产使用材料牌号与申报 PTR / 生物相容性报告中锁定的牌号不一致且未经变更验证。
