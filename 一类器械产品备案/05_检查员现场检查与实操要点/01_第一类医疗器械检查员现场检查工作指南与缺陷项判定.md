# 第一类医疗器械检查员现场检查工作指南与缺陷项判定（四川省检查员实操必备）

> **编制目的**：供四川省药品监督管理检查员开展第一类医疗器械生产现场检查、备案后回顾性检查及飞行检查参考。  
> **依据规范**：《医疗器械生产质量管理规范》（GMP）、《医疗器械监督管理条例》（739号令）及《医疗器械生产监督管理办法》（53号令）。  

---

## 一、 检查员现场核查“四大核心主线”

```
检查员现场核查
├── 主线 1：一致性核查（实物、配方、工艺与备案资料是否一致）
├── 主线 2：真实性核查（批记录、检验原始数据、留样、设备校准）
├── 主线 3：高类低报与违规宣称排查（严禁添加药物、严禁医美宣称）
└── 主线 4：质量体系有效运行（人员资质、厂房设施、供应商审核、不良事件）
```

---

## 二、 现场检查重点环节与常见严重缺陷项（赤线判定）

### 1. 原材料与采购控制环节
- **核查方法**：抽查仓库原材料账卡物、供应商资质档案、进货检验报告（COA）。
- **严重缺陷表现**：
  - 实际投料使用了备案资料中未载明的原料（例如：在“医用冷敷凝胶”中擅自添加**卡波姆以外的薄荷醇、中草药提取液、水杨酸**等成分）；
  - 原材料供应商变更未按变更控制程序进行风险评估与备案变更；
  - 关键原材料未制定内控技术标准或无批次进货检验记录。

### 2. 生产工艺与过程控制环节
- **核查方法**：深入车间查看实际操作路线、比对批生产记录（BPR）与备案申报工艺流程图。
- **严重缺陷表现**：
  - 现场工艺擅自删减关键质控步骤（如省略了初包装热合参数验证或关键过滤除菌工序）；
  - 批生产记录未实时填写，存在事后补填、代签字、“提前填好”等造假行为；
  - 生产环境温湿度、洁净度控制记录缺失，洁净车间压差不符合要求。

### 3. 成品检验与放行控制环节
- **核查方法**：现场核查理化检验室、微生物检验室仪器设备，现场调阅仪器原始图谱与检测记录。
- **严重缺陷表现**：
  - 企业自检报告中的项目，现场**根本没有对应检验仪器设备**（如技术要求规定了重金属、黏度指标，但化验室无原子吸收或黏度计，且未委托外检）；
  - 检验原始记录数据与报告结果不符，缺少标准曲线或计算过程；
  - 质量受权人/放行责任人未审核检验全项即签字放行上市。

### 4. 标签、说明书与包装合规性
- **核查方法**：在成品库抽取已包装待发货成品，逐字对照备案凭证附件中的《说明书》与《标签样稿》。
- **严重缺陷表现**：
  - 最小包装盒上印制了备案凭证未载明的功效（如“消炎镇痛、促进伤口愈合、术后修复”）；
  - 宣称非医疗器械用途（如“美白嫩肤、淡化色斑、抗衰修护”）；
  - 生产日期、使用期限未标注或与批号对应关系混乱。

## 三、 检查处置裁量标准

| 缺陷严重程度 | 现场发现情况判定 | 检查员建议处置措施 |
| :---: | :--- | :--- |
| **一般缺陷项** | 偶发性记录遗漏、标识未更新、培训档案未及时归档等不影响产品实质安全的问题 | 责令**限期整改**（通常为 15-30 个工作日内完成整改并提交复查报告） |
| **严重缺陷项** | 检验记录不真实、工艺发生重大变更未验证、检验能力缺失等 | 责令**立即暂停生产**，全面整改；符合立案条件的移交稽查执法部门立案调查 |
| **致命/违法行为** | **高类低报、提供虚假备案资料、非法添加药物成分、未经备案擅自生产** | **依法建议取消备案**；按《条例》81条/84条处以没收违法所得并处货值金额15-30倍罚款；涉嫌犯罪的**移送公安机关** |
