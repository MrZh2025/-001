# 医疗器械临床评价技术指导原则与免于临床评价目录速查

> **政策依据**：国家药品监督管理局通告 2021年第73号《医疗器械临床评价技术指导原则》  
> **核心法规**：《医疗器械监督管理条例》（国务院令第739号）第二十五条、《医疗器械注册与备案管理办法》（总局令第47号）  
> **重要目录**：《免于临床评价医疗器械目录》（国家药监局通告最新汇总版）  

---

## 一、 第二类医疗器械临床评价基本要求与路径选择

根据《医疗器械注册与备案管理办法》第三十四条规定，除**列入免于临床评价医疗器械目录**的产品外，第二类医疗器械注册申请人应当提交**临床评价资料**。

```
第二类医疗器械临床评价三条法定路径
├── 路径 1：列入《免于临床评价医疗器械目录》── 编写《免临床对比说明报告》
│   ├── 对比申报产品与《免临床目录》中描述的特征信息；
│   └── 对比申报产品与已上市同类产品的基本原理、结构组成、主要性能指标。
├── 路径 2：同品种医疗器械临床评价路径（CER 路径）── 最常用路径！
│   ├── 选取境内已批准上市的同品种医疗器械（主比对器械）；
│   ├── 开展 16 大要素全方位对比（原理、材质、性能、适用范围、操作方法等）；
│   ├── 搜集同品种器械的临床数据（文献数据、临床经验数据、不良事件数据）；
│   └── 针对申报产品与同品种产品的差异项，开展针对性非临床/临床验证，证明差异未引发新增风险。
└── 路径 3：开展临床试验路径（少数高风险/创新二类器械）
    ├── 在符合 GCP 要求的医疗器械临床试验机构开展；
    └── 提交伦理批件、试验方案、总结报告及统计分析报告。
```

---

## 二、 路径 1：免于进行临床评价的申报要求

### 1. 适用条件
申报产品在国家药监局发布的《免于临床评价医疗器械目录》（如常见医用冷敷贴/无菌敷贴、输液器、血压计、红外体温计、雾化器、简易牵引架、常规手术器械等）中能够找到对应子目录及产品描述。

### 2. 申报资料核心结构（免临床对比报告）
1. **与目录内容对比**：
   - 证明申报产品的**工作原理、结构组成、主要材料、预期用途、适用范围**与《目录》中的文字描述完全一致。
2. **与已获准境内注册同类产品对比**：
   - 选择至少 1 款境内已上市同类产品；
   - 列表比对：工作原理、材质与人体接触部件、关键性能指标（PTR对比）、灭菌方式、使用方法、禁忌证等；
   - 证明申报产品与已上市产品具有实质等同性。

---

## 三、 路径 2：同品种医疗器械临床评价（CER）实战编写指南

### 1. 同品种医疗器械的判定原则
所选同品种医疗器械应当是**在境内已批准上市**的合法医疗器械，且与申报产品在**基本原理、结构组成、制造材料（包括与人体接触材质）、生产工艺、性能要求、安全性评价、符合的国家/行业标准、预期目的、适用范围、使用方法**等方面基本等同。

### 2. 同品种对比 16 大关键要素对比表
| 对比维度 | 对比项目 | 审评关注重点 |
| :--- | :--- | :--- |
| **基本信息** | 产品名称、注册证号、生产企业 | 必须是境内有效上市注册证 |
| **技术特征** | 工作原理/作用机理 | 物理、声学、光学、机械原理是否相同 |
|  | 结构及组成 | 各模块、主机与附件、探头、管路等配置对比 |
|  | 生产材料/接触材料 | 接触人体材料牌号、生物相容性等级 |
|  | 性能要求与关键参数 | 产品技术要求（PTR）指标逐项横向对比 |
|  | 制造工艺与灭菌方式 | 灭菌工艺（EO/辐照/湿热）、无菌保证水平 |
|  | 软件与算法（若有） | 核心算法原理、软件功能模块、临床决策支持 |
| **生物学特征** | 接触性质与接触时间 | 表面接触/外部接入/植入；短期/长期 |
| **临床特征** | 适用范围与预期用途 | 适应症、预期使用科室、使用人群（成人/儿童） |
|  | 禁忌证与警告说明 | 禁忌人群、不良反应、操作警示 |
|  | 使用方法与操作流程 | 临床操作步骤、是否需专业人员操作 |

> [!IMPORTANT]
> **【CER 差异项分析：审评发补最高发频次区域】**：

### 3. 差异性分析与支持性证据（核心难点）
若申报产品与同品种存在差异（如材料牌号微调、结构尺寸不同、新增部分非核心功能）：
- **不可笼统忽略**，必须在 CER 报告中设立“差异性分析与评价”专门章节；
- 提供非临床研究数据（如台架试验对比、电气安全对比、生物相容性试验报告、体外模拟测试）证明该差异**未降低安全有效性**。

### 4. 同品种临床数据的收集与分析
- **科学文献检索**：CNKI、万方、PubMed 等数据库针对同品种器械的临床应用文献系统检索；
- **不良事件与召回数据**：检索国家不良事件监测数据、FDA MAUDE 数据库、NMPA 召回公告，评价已知风险。

## 四、 审查要点与常见发补问题排查

1. **同品种选择不当**：选择了境外上市但境内未获批的产品（境内同品种必须具有中国医疗器械注册证）。
2. **差异项论证不充分**：仅罗列了差异，未提供差异不影响产品安全有效性的试验数据或文献证据。
3. **扩大适用范围未提供证据**：申报产品适用范围宽于同品种获批范围，但未提供拓展部分的临床试验或专项数据支持。
4. **性能参数明显低于同品种**：未合理解释性能降低是否会影响临床预期效果。
