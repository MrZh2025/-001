# 第一类医疗器械产品目录（2021版）与01-22子目录速查

> **法规依据**：《第一类医疗器械产品目录》（国家药监局2021年第158号公告）及《实施通告》（2021年第107号）  

---

## 2021版第一类医疗器械子目录架构速查表（01-22）

| 子目录编码 | 子目录名称 | 常见第一类医疗器械产品举例 | 检查员核查要点 |
| :---: | :--- | :--- | :--- |
| **01** | **有源手术器械** | 手术照明灯、反光镜、手术放大镜、寻头仪 | 绝大多数有源手术设备为二/三类，一类仅限于辅助照明/观察类 |
| **02** | **无源手术器械** | 手术刀柄、医用剪、基础手术钳、镊、医用钩、骨凿、骨锤 | 材质通常为不锈钢/钛合金，无菌或非无菌提供，不含药理活性 |
| **03** | **神经和心血管手术器械** | 神经外科脑吸引器、心血管用组织镊（非植入） | 仅限非植入、基础手动操作器械 |
| **04** | **骨科手术器械** | 骨钻柄、骨刮匙、骨锯、复位钳、打入器、牵引弓 | 仅限手术辅助操作工具，**不得包含植入物** |
| **05** | **放射治疗器械** | 放射治疗定位膜、体位固定支架、铅字标记 | 仅限体外定位辅助耗材，不产生电离辐射 |
| **06** | **医用成像器械** | 医用胶片、超声耦合剂、透视防护屏 | 耦合剂严禁添加消毒/杀菌/美白药物成分 |
| **07** | **医用诊察和监护器械** | 听诊器、反光镜、压舌板、视力表、叩诊锤 | 基础手动诊察工具，无源物理检测 |
| **08** | **呼吸、麻醉和急救器械** | 口对口呼吸面罩、简易呼吸囊连接管、咬嘴 | 仅限非动力连接管路与基础辅助配件 |
| **09** | **物理治疗器械** | **医用冷敷贴、医用冷敷凝胶、医用冷敷头带** | **重点整治高发区**：仅限物理降温，严禁添加药物及美白祛斑成分 |
| **10** | **输血、透析和体外循环** | 止血带、压脉带、透析连接管卡子 | 基础外周辅助耗材，不与血液长期循环接触 |
| **11** | **医疗器械消毒灭菌器械** | 压力蒸汽灭菌化学指示卡、环氧乙烷指示胶带 | 灭菌过程监测耗材，本身非灭菌设备 |
| **12** | **有源植入器械** | *(本子目录无一类产品，全部为三类)* | 凡涉及有源植入一律为第三类 |
| **13** | **无源植入器械** | *(本子目录无一类产品，全部为三类)* | 凡涉及植入人体一律为第三类 |
| **14** | **注输、护理和防护器械** | **液体敷料、膏状敷料、医用隔离垫、隔离面罩** | **重点整治高发区**：仅限物理屏障，严禁添加透明质酸/重组胶原蛋白宣称抗衰 |
| **15** | **患者承载器械** | 轮椅车（手动）、医用病床、转移推车、拐杖 | 机械结构安全性、承重强度与稳定性 |
| **16** | **眼科器械** | 验光镜架、检眼镜片、眼科手术镊、弱视训练图表 | 仅限光学辅助检验及无源眼科工具 |
| **17** | **口腔科器械** | 牙科口镜、牙科镊、充填器、印模托盘 | 非植入、非长期接触口腔黏膜工具 |
| **18** | **妇产科、辅助生殖器械** | 妇科检查扩阴器（窥阴器）、脐带夹、羊膜穿刺针导引架 | 窥阴器为一次性或可重复使用基础检查工具 |
| **19** | **医用康复器械** | 训练用哑铃、平衡板、步行训练助行架、防褥疮床垫 | 物理机械康复辅助器械 |
| **20** | **中医器械** | 针灸针（非无菌拔罐器/刮痧板）、艾灸器具 | 艾灸器具仅限加热器具，**艾条本身不属于医疗器械** |
| **21** | **医用软件** | 图像显示软件组件（不含诊断算法/处理分析） | 凡带有辅助诊断、病灶分割、AI分析的均为二/三类 |
| **22** | **临床检验器械** | 样本保存液、自动脱水机、显微镜玻片、染色架 | 样本前处理工具与设备，不含诊断试剂核心反应 |
