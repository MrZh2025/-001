# 附件：医疗器械产品技术要求编写指导原则

## 一、 适用范围

本指导原则适用于申请**注册或者备案**的医疗器械产品，包括体外诊断试剂产品。  
本指导原则仅对医疗器械产品技术要求的**格式和内容**提出一般性要求，不对具体产品的性能指标和检验方法进行规定。

---

## 二、 基本要求

1. **合法合规性**：产品技术要求的编制应当符合国家相关法律法规、部门规章及强制性标准的规定。
2. **术语规范性**：产品技术要求应当使用规范、通用的专业术语。涉及特殊术语的，应当在“术语”部分提供明确定义；不得使用与标准术语名称相同但内涵改变的自定义术语。
3. **对应性原则**：检验方法各项内容的编号原则上应当与性能指标各项内容的编号完全相对应（如性能指标 2.1 对应检验方法 3.1）。
4. **标准化与规范化**：文字、数字、公式、计量单位、符号、图表等应当符合国家标准化相关规范要求。
5. **引用标准规范**：引用国家标准或行业标准的，应当注明标准编号及年代号（如 GB 9706.1-2020）。

---

## 三、 产品技术要求的主要内容和编写要求

产品技术要求的内容一般包括：**产品名称、产品型号/规格及其划分说明、性能指标、检验方法、术语（如适用）以及附录（如适用）**。

### （一） 产品名称
* 产品名称应当使用中文，并与申请注册或备案的医疗器械通用名称完全一致。
* 产品名称应当符合《医疗器械通用名称命名规则》的要求。

### （二） 产品型号/规格及其划分说明
1. **明确型号与规格**：应当明确产品所有的型号和规格。
2. **型号规格划分说明**：对于同一注册/备案单元内包含多种型号、规格的产品，应当清晰、明确地阐述各型号、规格之间的技术参数、外观尺寸、结构组成或材质差异（推荐采用**对比表格或图示说明**）。
3. **软件产品要求**：含有医用软件或者独立医用软件的产品，应当在型号规格划分说明中明确**软件发布版本**以及**软件完整版本命名规则**。
4. **灭菌/提供状态**：明确说明产品是以无菌状态提供还是非无菌状态提供；无菌提供的应当注明灭菌方式（如环氧乙烷灭菌、辐射灭菌、湿热灭菌等）。

### （三） 性能指标
1. **客观可判定性**：性能指标应当是能够进行客观判定的**成品功能性、安全性指标**，具有量化数值或明确的判定标准。
2. **符合强制性标准**：性能指标应当充分考虑适用的国家标准、行业标准，**不得低于强制性国家/行业标准的要求**。
3. **明确具体数值**：性能指标应当明确具体要求，**不得使用“见随附资料”、“按供货合同执行”、“符合相关要求”等模糊、主观或无明确判据的表述**。
4. **排除非成品评价内容**：产品的设计开发验证性评价（如生物相容性评价、动物实验评价、包装运输模拟验证等）原则上不应作为成品性能指标写入产品技术要求中。

### （四） 检验方法
1. **与指标一一对应**：检验方法的各项编号原则上应当与第二部分性能指标的编号保持一一对应。
2. **科学、可操作与可重现**：检验方法应当具体、详尽、具备可操作性和科学重现性，明确所需的检验仪器设备、试验条件、试剂配制、操作步骤、计算公式及结果判定方法。
3. **优先采用标准方法**：优先引用适用的国家标准、行业标准中公认的检验方法；若有修改或采用自建检验方法的，应当在研究资料中提供方法学验证资料。

### （五） 术语（如适用）
* 如产品技术要求中使用了特有的或非通用的术语、缩略语，应当在正文中单设“术语”章节进行明确定义。通用术语或已有国家/行业标准明确定义的术语无需重复列出。

### （六） 附录（如适用）
1. **原材料与接触材质**：通常应以附录形式列明产品的主要原材料清单，以及直接或间接接触人体的部件材质牌号与质量标准。
2. **电气安全图示**：有源医疗器械可在附录中提供绝缘路径图、电气间隙与爬电距离说明图、系统组成架构图等。
3. **体外诊断试剂（IVD）特殊要求**：第三类体外诊断试剂还应当在附录中明确主要原材料的来源、生产工艺及主要半成品的质量控制要求。

## 四、 产品技术要求编写格式与参考模板

```markdown
                     医疗器械产品技术要求编号：______________

                              [产品通用名称]

1. 产品型号/规格及其划分说明
   1.1 产品型号与规格
   1.2 型号规格划分说明及差异表
   1.3 结构组成及图示
   1.4 交付状态及灭菌方式

2. 性能指标
   2.1 外观与物理性能
   2.2 化学性能（如适用）
   2.3 电气安全与电磁兼容性能（有源产品适用）
   2.4 微生物学性能 / 无菌（如适用）

3. 检验方法
   3.1 外观与物理性能检验
   3.2 化学性能检验
   3.3 电气安全检验
   3.4 微生物学检验

4. 术语（如适用）

附录 A：主要原材料及接触人体材质清单（规范性附录）
附录 B：电气绝缘图 / 系统架构图（如适用）
```

## 五、 现场检查员核查要点（四川省检查员实操必备）

1. **一致性核查**：现场核查企业成品检验规程（SOP）、批检验记录是否严格按照经备案/注册的《产品技术要求》执行。
2. **全项检验覆盖**：自检报告或外检报告必须 **100% 覆盖 PTR 中所列全部性能指标**，不得无故漏检。
3. **设备能力匹配**：现场核对实验室检验仪器设备清单，企业声称具备自检能力的 PTR 指标，必须有对应的仪器设备并处于计量检定/校准有效期内。
